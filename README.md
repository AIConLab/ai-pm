# ai-pm

AI PM project source code


## Dir structure

- `ai-pm`
- `minecraft-data`
- `paper`
- `.docker`

## Starting

Minecraft:
```
./scripts/start_minecraft.sh
./scripts/start-auto-backup-mc-world.sh
```

AIPM:
```
./scripts/start_aipm.sh
```

## Stopping


Minecraft:
```
./scripts/stop_minecraft.sh
./scripts/stop-auto-backup-mc-world.sh
```

AIPM:
```
./scripts/stop_aipm.sh
```
